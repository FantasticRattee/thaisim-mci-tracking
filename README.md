# ThaiSIM MCI Tracking

เว็บทดลองติดตามผู้ป่วยในสถานการณ์จำลองสาธารณภัยหมู่ สำหรับบันทึกและดูการเคลื่อนย้ายผู้ป่วยระหว่างจุดปฏิบัติงาน

- ภาพรวมสถานการณ์และจำนวนผู้ป่วยตามสีคัดแยก
- แฟ้มผู้ป่วยและประวัติการอัปเดต พร้อมสัญญาณชีพ หัตถการ และปลายทางส่งต่อ
- พื้นที่ปฏิบัติงานและสถานะการชำระล้าง
- คลังเวชภัณฑ์และระดับแจ้งเตือน
- ดัชนีคู่มือสารเคมี ค้นด้วยเลข UN หรือชื่อสาร
- การ์ด QR สำหรับพิมพ์และสแกนเข้าแฟ้มเดิมหรือขึ้นทะเบียนผู้ป่วยตามรหัสบนการ์ด

ข้อมูลเริ่มต้นเป็นข้อมูลสมมติสำหรับการฝึกซ้อม เจ้าหน้าที่เป็นผู้เลือกสีคัดแยกและบันทึกข้อมูลด้วยตนเอง ใช้ชื่อสมมติและเลี่ยงการกรอกข้อมูลผู้ป่วยจริง

## รันในเครื่อง

ติดตั้ง Node.js 22 แล้วรันคำสั่งต่อไปนี้

```sh
npm ci
cp .env.example .env
```

ตั้งรหัสเข้าเดโม `DEMO_PASSCODE` และค่าสุ่มสำหรับ `SESSION_SECRET` ใน `.env` แล้วเริ่มเว็บ

```sh
node --env-file=.env src/server.js
```

เปิด [localhost:3000](http://localhost:3000) ใส่รหัสเข้าเดโมและกรอกชื่อสมมติของเจ้าหน้าที่ ทีมที่ใช้ฐานข้อมูลเดโมนี้จะใช้รหัสเข้าร่วมเดียวกัน

```sh
npm test
```

## Deploy บน Railway

ใช้ Dockerfile ที่อยู่ใน repo ตั้ง `DEMO_PASSCODE` และ `SESSION_SECRET` ใน Railway Variables สร้างโดเมนสำหรับเว็บ และผูก Volume ที่ `/data` เพื่อเก็บ SQLite เมื่อ redeploy ระบบใช้โดเมนของ Railway สร้างลิงก์บน QR หากใช้โดเมนอื่น ตั้ง `PUBLIC_ORIGIN` เป็น URL เต็มของเว็บ

เว็บไซต์มี endpoint `/healthz` สำหรับตรวจสอบว่าเซิร์ฟเวอร์พร้อมให้บริการ
